# algotrader-app
Interactive Streamlit platform to showcase developments from [algotrader-playground](https://github.com/jctaylor11/algotrader-playground). Backtest strategies, visualise performance, and optimise parameters.

## Features
- Interactive strategy backtesting
- Strategy parameter optimisation
- Performance visualisation 

## Planned Features
- [ ] Download and cache custom market data using Binance APIs
- [ ] Walk forward analysis to avoid overfitting
- [ ] Event-driven backtest engine to avoid lookahead bias  
- [ ] Monte Carlo simulation for performance confidence intervals

## Tech Stack
Python | Pandas | NumPy | Streamlit | Plotly
